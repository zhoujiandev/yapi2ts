# 常见问题

## <a id="faq"></a> 常见问题

### 项目配置与 Token 问题

**Q: 插件的配置页面在哪里？如何配置项目？**

A: 自 v1.3.0 起，插件已移除“我的项目”图形配置面板，全面改为代码协作配置模式。您需要直接打开工作区根目录下的 `.vscode/settings.json` 文件，并添加 `yapi2ts.projects` 项进行配置。

**Q: 如何获取 YAPI 项目 Token？**

A: 登录 YAPI 系统 → 进入目标项目 → 点击右上角「设置」 → 找到「token 配置」 → 复制 Token。

**Q: Token 应该写在哪里？直接写在配置文件中会被提交到 Git 仓库吗？**

A: 插件提供了两种配置 Token 的方式：

1. **明文配置（不推荐）**：直接在 `settings.json` 中对应的项目对象里填写 `projectToken` 属性。这种方式下，如果配置文件被提交至公共仓库，会造成 Token 泄露。
2. **Keychain 托管（推荐）**：在 `settings.json` 中配置项目时**省略** `projectToken` 字段。在首次点击“连接”时，插件会弹出输入框提示您在本地输入 Token。该 Token 将会被加密保存到操作系统的安全密钥串（Keychain）中，不会被写入设置文件或提交至 Git 仓库。

**Q: 提示 "Token 无效" 或 "认证失败"？**

A: 请检查：

1. 输入或配置的 Token 是否复制完整，有无多余的前后空格。
2. 该 Token 在 YAPI 平台中是否已被项目管理员重置。
3. `yapiUrl` 配置是否正确（应包含 `http://` 或 `https://`）。
4. 连接失败时，Keychain 中保存的旧 Token 会被自动清除，您只需在下次连接时重新输入最新有效的 Token。

**Q: 如何清除本地已保存的 Keychain Token？**

A: 按下 `Cmd+Shift+P` (Mac) 或 `Ctrl+Shift+P` (Windows) 打开命令面板，输入并执行命令：`YAPI TypeScript: Clear Stored Project Tokens (清除已保存的项目 Token)` 即可一键清除。

### 网络连接问题

**Q: 提示 "连接失败" 或 "网络错误"？**

A: 请检查：

1. YAPI 服务器是否可访问（在浏览器中打开 YAPI 地址测试）
2. 是否需要 VPN 或内网访问
3. 防火墙是否阻挡了请求
4. YAPI 地址是否包含端口号（如 `http://yapi.company.com:3000`）

**Q: 公司内网的 YAPI 无法访问？**

A: 确保编辑器和 YAPI 服务器在同一网络环境下，或配置正确的代理设置。

### 接口数据问题

**Q: 连接成功但接口列表为空？**

A: 请检查：

1. YAPI 项目中是否已添加接口
2. 接口是否在某个分类下（点击左侧分类树查看）
3. Token 是否有该项目的访问权限

**Q: 部分接口没有显示？**

A: 插件会加载所有分类下的接口，请检查是否选择了正确的分类，或使用搜索功能查找。

### 代码生成问题

**Q: 生成的类型不完整或为 `any`？**

A: 这通常是因为 YAPI 接口的请求/响应数据未定义 JSON Schema。请在 YAPI 中完善接口的参数和返回数据定义。

**Q: 方法名生成不符合预期？**

A: 插件会根据接口路径自动生成方法名。如果需要自定义，可以在生成后手动修改，或调整模板。

### 模板问题

**Q: 模板语法错误导致生成失败？**

A: 请检查：

1. EJS 语法是否正确（`<%- variable %>`、`<% code %>`）
2. 变量名是否拼写正确（参考模板变量表）
3. 条件语句是否正确闭合（`<% if (...) { %>` 必须有对应的 `<% } %>`）

**Q: 如何恢复默认模板？**

A: 打开命令面板（`Ctrl+Shift+P`），输入并执行 `YAPI TypeScript: Reset Templates`。

### 其他问题

**Q: 插件没有显示在侧边栏？**

A: 请检查：

1. 插件是否已正确安装并启用
2. 尝试重启编辑器
3. 检查编辑器版本是否 >= 1.50.0

**Q: 如何反馈问题或建议？**

A: 请在 [GitHub Issues](https://github.com/zhoujiandev/yapi2ts/issues) 提交，并提供详细的问题描述和复现步骤。
