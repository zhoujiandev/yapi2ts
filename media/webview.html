如何配置 YAPI 项目？

1
打开项目根目录下的 .vscode/settings.json 文件
2
在设置中配置项目信息。推荐省略 projectToken 以防提交到 Git 仓库，连接时插件会安全地提示您在本地输入： 
"yapi2ts.projects": [
  {
    "id": "my-project",
    "name": "我的项目",
    "yapiUrl": "http://yapi.example.com"
  }
]
💡 提示：如果在私有仓库，也可以直接加上 "projectToken": "your-token"。
可在 YAPI 网站的 “项目设置 -> token配置” 页面获取 Token。
3
保存文件后，插件会自动读取配置，您可以在接口列表中看到配置的项目。

模板管理

自定义模板用于生成符合您项目规范的TypeScript接口调用代码。 模板基于 EJS 引擎，推荐使用 EJS 语法：<%- methodName %> 输出变量，<% if (isGet) { %> 条件判断。 也兼容 ES6 模板字符串语法 \${methodName}（会自动转换为 EJS）。 系统将自动添加 JSDoc 注释（@description、@url、@param），其中 @param 无法被覆盖。

/** * @JSDoc说明 如无需添加额外的JSDoc标签，可以把模板的整个JSDoc注释去掉 */ export const <%- methodName %> = (params: <%- paramsTypeName %>, config?: Omit<AxiosRequestConfig, <%- isNotGet ? '"data"' : '"params"' %>>): Promise<<%- responseTypeName %>> => { return axios.<%- lowerCaseMethod %>('<%- path %>', <%- isNotGet ? 'params, config' : '{ params, ...config }' %>); };

建议：在编辑器中编写模板代码，这样可以获得语法高亮和代码提示，复制粘贴到模板编辑器中。
