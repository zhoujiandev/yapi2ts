# YAPI TypeScript Extension Development Guidelines (.CLAUDE.md)

This file contains coding guidelines, build commands, and standards for the `yapi2ts` VS Code extension project.

## Build Commands

Use `pnpm` as the package manager:

- **Type Check**: `pnpm run compile:check`
- **Build (Development)**: `pnpm run compile`
- **Watch Mode**: `pnpm run watch`
- **Build (Production)**: `pnpm run package`
- **Full Build & Git Add**: `pnpm run compile:full`

## Lint & Formatting

- **Lint Check**: `pnpm run lint:check`
- **Lint Auto-fix**: `pnpm run lint`
- **Prettier Format Check**: `pnpm run format:check`
- **Prettier Format Auto-fix**: `pnpm run format`

## Test Commands

- **Run Integration Tests**: `pnpm run test`
- **Run CI Tests**: `pnpm run test:ci`
- **Compile Tests**: `pnpm run compile-tests`
- **Watch Tests**: `pnpm run watch-tests`

## Code Style & Conventions

### 1. TypeScript & ES2022

- **Strict Typing**: Strict mode is enabled (`"strict": true`). Specify types explicitly for parameters, return values, and variables where type inference is not clear. Avoid using `any` type.
- **Async/Await**: Prefer `async/await` over promise chaining (`.then().catch()`).
- **Error Handling**: Always wrap asynchronous API operations and VS Code commands in `try/catch` blocks. Use `new Error()` instead of throwing string literals (`no-throw-literal`).

### 2. Formatting & Syntax

- **Indentation**: 4 spaces.
- **Semicolons**: Required at the end of statements.
- **Quotes**: Single quotes (`'`) for string literals and imports.
- **Equality**: Use triple equals (`===` and `!==`) instead of `==` and `!=`.
- **Braces**: Always use curly braces for all control statements (`if`, `else`, `for`, `while`), even if they are single lines.

### 3. VS Code API & Resource Management

- **Disposables**: Push all commands, event listeners, and webview provider registrations to `context.subscriptions` to ensure proper resource cleanup:
    ```typescript
    const disposable = vscode.commands.registerCommand('yapi2ts.someCommand', async () => { ... });
    context.subscriptions.push(disposable);
    ```
- **VS Code Imports**: Always import VS Code via namespace import:
    ```typescript
    import * as vscode from 'vscode';
    ```

### 4. File Structure

- `src/extension.ts`: Extension activation and command registrations.
- `src/webviewProvider.ts`: Webview UI panel logic and message bridge between the Webview and Extension host.
- `src/codeGenerator.ts`: Code generation logic (converting YAPI schema to TS interfaces/functions).
- `src/yapiService.ts`: Requests to YAPI server API and data processing.
- `src/types.ts`: Global type definitions.

### 5. UI & Icon Conventions (Webview)

- **Icons & Images**: Always use Lucide icons or custom beautifully-designed SVG icons. Prohibit using emoji icons (e.g., 📁, 📋, 💡) in the UI.
